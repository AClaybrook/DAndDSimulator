# Damage leaderboard

Expected damage per round of every example build (62) at each act checkpoint, against one reference enemy per act (Act 1 reference (AC 14), Act 2 reference (AC 16), Act 3 reference (AC 18); no resistances), single target, 3 round fights. Every build gets the same outside help in each scenario; its own buffs are removed except Hex and Divine Favour. Each build uses its own planned gear for the act. Generated by `python -m bg3.leaderboard`; the full specs are in `bg3/data/leaderboard.json` and the planner has the same leaderboard with your party in it.

Reddit (approx.) builds are rebuilt from the Reddit index (classes and key items only), so treat them as rough. Area damage (Fireball, Spirit Guardians) counts one enemy here, so casters rank low; see the planner's enemies setting.
