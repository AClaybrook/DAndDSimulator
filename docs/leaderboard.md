# Damage leaderboard

Expected damage per round of every example build (78) at each act checkpoint, against one reference enemy per act (Act 1 reference (AC 14), Act 2 reference (AC 16), Act 3 reference (AC 18); no resistances), 3 round fights. Generated by `python -m bg3.leaderboard`; every run is kept with each build's full spec in `local_data/bg3.sqlite`, and the planner has the same leaderboard with your party in it, other scenarios and 1 to 4 enemies.

Reddit (approx.) builds are rebuilt from the Reddit index (classes and key items only), and build doc builds without ability scores use a guessed point buy, so treat both as rough. Overall: the average over the three acts of the build's damage as a share of the best build at that act (100 = best in every act).
